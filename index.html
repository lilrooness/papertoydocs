User Guide

Papertoy is a game engine and language for creating card games. It understands concepts like players, turns, phases, cards, stacks of cards, and interesting ways in which cards can move between stacks.

Care has gone into the development of each concept, but the language is constantly under development! New features enabling you to develop more types of games, will be added over time.
